# Party visual language

This application uses a consistent editorial colour system for election data.

The AEC identifies parties and candidates but does not prescribe a universal statutory colour for each party or for independents; campaign colours may vary. Accordingly, these are application conventions, chosen for consistency and accessibility rather than presented as official VEC/AEC colours.

- Labor — red
- Coalition / Liberal — blue
- Nationals — dark Nationals green (`#006946`)
- Greens — brighter Greens green (`#009C3D`)
- One Nation — orange
- Independent — neutral slate
- Teal-aligned independent — the same neutral slate with a narrow vertical teal stripe centred about two-thirds across the swatch. This preserves the candidate's legal/electoral status as an independent while conveying the commonly used descriptive grouping.
- Other party — muted ochre
- Combined Other / Independent model buckets — neutral taupe, because the underlying model category combines unlike candidates and should not be visually represented as a single political identity.

The Nationals and Greens both conventionally use green. Parliamentary Education Office guidance explicitly distinguishes the Nationals' darker green from the Greens' brighter green. The Victorian Nationals' own current material uses green with yellow/white branding; black-and-white versions exist as monochrome reproduction treatments, but black and white are not the party's primary identifying colours. The application therefore preserves green for both while using substantially separated dark and bright tones.

Colour must never be the only carrier of meaning: labels remain visible in keys, tables and accessible descriptions.
