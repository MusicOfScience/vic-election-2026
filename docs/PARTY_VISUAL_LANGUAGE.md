# Party visual language

This application uses a consistent editorial colour and mark system for election data.

The AEC and VEC identify parties and candidates but do not prescribe a universal statutory colour for each party or for independents; campaign colours may vary. These are therefore application conventions chosen for consistency, recognisability and accessibility rather than presented as official VEC/AEC colours.

- Labor — red
- Coalition / Liberal — blue
- Nationals — very dark green (`#003B2B`) with a yellow secondary accent
- Greens — brighter green (`#009C3D`)
- One Nation — orange
- Independent — neutral slate
- Teal-aligned independent — the same neutral slate with a narrow teal accent. This preserves the candidate's legal/electoral status as an independent while conveying the commonly used descriptive grouping.
- Other party — muted ochre
- Combined Other / Independent model buckets — neutral taupe, because the underlying model category combines unlike candidates and should not be visually represented as a single political identity.

The Nationals and Greens both conventionally use green. Parliamentary Education Office guidance distinguishes the Nationals' darker green from the Greens' brighter green, while current Victorian Nationals material uses green with yellow/white branding. Because dark green alone can still be difficult to distinguish in dense charts, the application uses yellow as a secondary Nationals cue rather than replacing the party's green identity with black.

The cue adapts to the visualisation. Blocks, bars and swatches use very dark green with a yellow diagonal accent. Where Nationals and independents are plotted as separate line series, Nationals use a yellow under-stroke/halo with a dark-green foreground and distinct marker; independents use a slate dashed line and square-style marker. Teal-aligned independents remain slate-led with a teal marker/accent.

Colour must never be the only carrier of meaning: labels, line styles, marker shapes and accessible descriptions remain available.

The explanatory key is accessed from the main navigation as **How to read** rather than floating persistently over the application, particularly on mobile.
